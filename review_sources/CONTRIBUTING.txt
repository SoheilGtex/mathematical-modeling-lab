EXAM REVIEW SOURCE CONVENTIONS
==============================

Never edit EXAM_NIGHT.md or site_docs/exam.en.md/.fa.md directly.
They are generated by: python scripts/build_exam_night.py
CI verifies all three with: python scripts/build_exam_night.py --check

For every new sessions/session_NN/ directory, add both:
  review_sources/session_NN.en.md
  review_sources/session_NN.fa.md

For every new published site_docs/assignments/slug.en.md and slug.fa.md pair,
add both:
  review_sources/assignment_slug.en.md
  review_sources/assignment_slug.fa.md

Content must cover model formulation only: decision variables, objective,
constraints, variable domains, units, indexing, boundary assumptions.
Exclude numerical optimal plans, optimality proofs and solver instructions.
Complete worked solutions stay on their existing dedicated site pages.

Each source begins with a ### heading. Links to a full site page are written
relative to site_docs/, e.g. [Diet](session-01/diet.md). The generator checks
both language-specific pages exist, and rewrites these links for EXAM_NIGHT.md.

Run before PR:
  python scripts/build_exam_night.py
  python scripts/build_exam_night.py --check
  python -m pytest -q
  python scripts/check_site_docs.py
  python -m mkdocs build --strict
