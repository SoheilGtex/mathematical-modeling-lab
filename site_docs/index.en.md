# Mathematical Modeling Lab

**Elementary Mathematical Modeling · Fall 2026 · Kharazmi University**

**Project contributors:** **[Soheil Salmani](https://github.com/SoheilGtex)** and **[Mahdieh Moghiseh](https://github.com/mahdiehmg)**. This independent educational project includes mathematical models, worked solutions, and optional Python and Julia learning materials.

This is an independent student project, **not an official university or instructor resource**. Material drawn from the class notes is distinguished from additional solutions and examples.

## Course materials

Use the navigation menu for complete session notes and worked solutions. Two independent study guides are available: **[Midterm Review](exam.md)** for Sessions 01–09, including a day-before study plan and self-test, and **[Final Exam Review](exam-final.md)** for Sessions 10 onward.

## Code and computation

The [GitHub repository](https://github.com/SoheilGtex/mathematical-modeling-lab) contains the Python implementations, runnable examples, and tests. Further details are available in the optional [technical notes](reference/index.md). No code is required to follow the written solutions.

Explore the optional [Julia learning](julia/index.md) materials. Julia is an optional programming supplement; exam preparation is separated by examination period.
