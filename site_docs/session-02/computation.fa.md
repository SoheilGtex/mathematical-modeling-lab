# جلسهٔ دوم — یادداشت‌های محاسباتی

**تفکیک منبع و افزوده‌ها:** تنها صفحهٔ دست‌نویس، مدل نمادین حمل‌ونقل و مدل تلویزیون با ظرفیت تصحیح‌شدهٔ ۶۰٬۰۰۰ نفرساعت را ارائه می‌کند. جواب‌های عددی حل‌کننده، توسعهٔ صحیح و نمونهٔ حمل‌ونقل ۲×۲ افزودهٔ آموزشی مستقل هستند.

## مدل‌های ریاضی

- **حمل‌ونقل:** $\min\sum_{i,j}c_{ij}x_{ij}$ با قیود عرضه $\sum_jx_{ij}\le a_i$، تقاضا $\sum_ix_{ij}=b_j$ و $x_{ij}\ge0$.
- **تلویزیون:** $\max 60x_1+30x_2$ با قید کار $20x_1+15x_2\le H$ و کران‌های $0\le x_1\le2000$ و $0\le x_2\le4000$.

در پیاده‌سازی `LinearProgram` فقط فرم `A_ub @ x <= b_ub` به‌صورت مستقیم پشتیبانی می‌شود. بنابراین هر تساوی تقاضا با دو نامساوی $\sum_i x_{ij}\le b_j$ و $-\sum_i x_{ij}\le-b_j$ نمایش داده می‌شود؛ این دو معادل تساوی‌اند و هیچ کاهش تقاضایی مجاز نیست.

**هشدار:** استفاده هم‌زمان از `--integer --plot` برای مدل تلویزیون به معنی نمایش میلیون‌ها نقطهٔ صحیح است؛ ابزار ترسیم عمداً آن را رد می‌کند. برای شکل ناحیهٔ مجاز، حالت پیوسته را رسم کن؛ برای جواب صحیح، فقط حل عددی را اجرا کن.
