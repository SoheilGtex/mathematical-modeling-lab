# Session 05 — Fractional Programming and Fuzzy Sets

This seven-page handwritten lecture note covers **two distinct topics**:

1. **Pages 1–3:** the Charnes–Cooper change of variables that converts a linear-fractional objective into a linear program when its denominator is positive, followed by a numerical example.
2. **Pages 4–7:** crisp and fuzzy sets, membership grades, and a **triangular fuzzy number** with vertices $(1,0)$, $(5,1)$ and $(7,0)$.

The handwritten note supplies the definitions, the numerical data and the displayed transformations. The full transformed constraints, optimal objective value and rigorous proof are **independent study additions**. No fuzzy-optimization problem is invented from the notes, and the scanned material is not redistributed.
