# جلسهٔ پنجم — محاسبات تکمیلی (اختیاری)

مثال کسری صفحات ۱ تا ۳ پس از **تبدیل چارنز–کوپر** با حل‌کنندهٔ خطی SciPy/HiGHS حل می‌شود. مثال صفحات ۴ تا ۷ مقدار **تابع عضویت** را محاسبه می‌کند؛ مسئلهٔ بهینه‌سازی فازی جدیدی ایجاد نشده است.

پس از نصب وابستگی‌های Python در پوشهٔ اصلی پروژه، اجرا کنید:

```bash
python examples/session_05/01_fractional_charnes_cooper.py
python examples/session_05/02_triangular_fuzzy.py
```

نتیجهٔ بهینهٔ کسری که مستقلاً محاسبه و بررسی شده است:

$$x^*=(0,50/3),\quad (y_1^*,y_2^*,t^*)=(0,5/26,3/260),\quad f^*=103/26.$$

برای تابع عضویت مثلثی نیز $\mu(1.2)=0.05$ مطابق جزوه و $\mu(6)=0.5$ به‌عنوان مثال تکمیلی به دست می‌آید. محاسبات عددی اختیاری‌اند و در مرور شب امتحان فقط **فرمول‌بندی** نوشته می‌شود.
