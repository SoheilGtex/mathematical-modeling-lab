# آموزش زبان جولیا

**مشارکت‌کنندگان پروژه:** [سهیل سلمانی](https://github.com/SoheilGtex) · [مهدیه مقیسه](https://github.com/mahdiehmg)

این آموزش‌های مقدماتی Julia، بخشی اختیاری و تکمیلی در کنار مباحث مدل‌سازی ریاضی هستند.
بخش Julia از پیاده‌سازی‌های پایتون و از **مرور شب امتحان مبتنی بر مدل‌سازیِ تمام جلسات و تمرین‌ها** جداست.

## مباحث مقدماتی موجود

- [متغیرها](https://github.com/SoheilGtex/mathematical-modeling-lab/blob/main/Julia/01_Basics/01_variables.jl): تعریف متغیر و محاسبهٔ هزینهٔ تولید
- [ساختارهای کنترلی](https://github.com/SoheilGtex/mathematical-modeling-lab/blob/main/Julia/01_Basics/04_control_flow.jl): شرط‌ها و حلقه‌ها
- [توابع](https://github.com/SoheilGtex/mathematical-modeling-lab/blob/main/Julia/01_Basics/05_functions.jl): آرگومان، مقدار بازگشتی و محاسبات قابل استفادهٔ مجدد

## نحوهٔ اجرا

پس از [نصب Julia](https://julialang.org/downloads/)، از مسیر اصلی مخزن دستورهای زیر را اجرا کنید:

```bash
julia Julia/01_Basics/01_variables.jl
julia Julia/01_Basics/04_control_flow.jl
julia Julia/01_Basics/05_functions.jl
```

برای این مثال‌ها فقط خود Julia لازم است؛ نصب **JuMP یا HiGHS** ضروری نیست.
آموزش‌های بهینه‌سازی و مثال‌های درسی فعلاً در برنامهٔ توسعه هستند و هنوز منتشر نشده‌اند.
