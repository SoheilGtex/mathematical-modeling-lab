# آزمایشگاه مدل‌سازی ریاضی

**مدل‌سازی مقدماتی ریاضی · پاییز ۱۴۰۵ · دانشگاه خوارزمی**

**مشارکت‌کنندگان پروژه:** **[سهیل سلمانی](https://github.com/SoheilGtex)** و **[مهدیه مقیسه](https://github.com/mahdiehmg)**. این مجموعهٔ آموزشی مستقل شامل مدل‌های ریاضی، حل‌های تشریحی و مطالب تکمیلی Python و Julia است.

این سایت یک پروژهٔ دانشجویی مستقل است و **منبع رسمی دانشگاه یا استاد نیست**. داده‌ها و مدل‌های برگرفته از جزوهٔ کلاس، از حل‌ها و مثال‌های تکمیلی تفکیک شده‌اند.

## مطالعهٔ درس

برای مطالعهٔ هر جلسه و حل تشریحی مسائل آن، از فهرست جلسات در منوی سایت استفاده کنید. [مرور شب امتحان](exam.md) نیز برای جمع‌بندی مطالب در یک صفحه در دسترس است و با اضافه‌شدن جلسات جدید تکمیل می‌شود.

## کدها و محاسبات

[مخزن GitHub پروژه](https://github.com/SoheilGtex/mathematical-modeling-lab) شامل کدهای پایتون، مثال‌های اجرایی و آزمون‌هاست. توضیحات بیشتر در [بخش فنی](reference/index.md) آمده است. برای مطالعهٔ حل‌های تشریحی نیازی به اجرای کد نیست.

## آموزش جولیا

[آموزش جولیا](julia/index.md) بخش محاسباتی تکمیلی پروژه است؛ مرور شب امتحان فقط بر مدل‌سازی ریاضی تمرکز دارد.
