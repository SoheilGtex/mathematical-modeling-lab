# محاسبات جلسهٔ چهارم (اختیاری)

سه مدل این جلسه از جزوهٔ چهارصفحه‌ای کلاس استخراج شده‌اند. کدها فقط برای بررسی مستقل جواب‌ها هستند؛ در **مرور شب امتحان** نه اجرای نرم‌افزار لازم است و نه محاسبهٔ جواب بهینه.

```bash
python examples/session_04/01_machine_allocation.py
python examples/session_04/02_crude_oil.py
python examples/session_04/03_revenue_cost_ratio.py
```

پیش از اجرا، محیط مجازی Python را فعال کن و `python -m pip install -e ".[dev]"` را اجرا کن. دو مسئلهٔ اول **برنامه‌ریزی خطی پیوسته** هستند و با SciPy HiGHS حل می‌شوند. سومی **برنامه‌ریزی کسری خطی** است که صرفاً برای ضرایب ویژهٔ این سؤال می‌توان آن را به بیشینه‌سازی هزینهٔ متغیر تبدیل کرد؛ این روش، حل‌کنندهٔ عمومی برنامه‌ریزی کسری نیست.

| مسئله | جواب بهینهٔ محاسبه‌شدهٔ مستقل | واحد |
| --- | ---: | --- |
| سه محصول و چهار ماشین | ۸۲٬۵۰۰ | دلار، هزینهٔ کل |
| دو نفت خام و سه فرآورده | ۵۰٬۹۵۱٬۰۸۶٫۹۶ | دلار، هزینهٔ خرید |
| نسبت درآمد به هزینهٔ دو محصول | $20/11\approx1.81818$ | بدون واحد |

برای اثبات بهینگی و شرح کامل از صفحات [ماشین‌ها](machines.md)، [پالایش نفت](crude.md) و [هدف کسری](ratio.md) استفاده کنید. این آپدیت فایل‌های Julia را تغییر نمی‌دهد.
