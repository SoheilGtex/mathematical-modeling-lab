# جلسهٔ هفتم — بررسی محاسباتی اختیاری

بعد از نصب وابستگی‌های Python، از ریشهٔ مخزن این دستورها را اجرا کنید:

```bash
python examples/session_07/01_ranked_lr_lp.py
python examples/session_07/02_extension_kerre.py
python -m pytest tests/test_session_06_07.py -q
```

برنامهٔ اول مدل چهارتایی‌های LR در صفحهٔ ۴ را **بر پایهٔ تابع رتبه‌بندی** حل می‌کند. جواب مورد انتظار $x_1=77/96$ و $x_2=25/16$ با مقدار هدف $R(Z)=755/96$ است.

برنامهٔ دوم بیشینهٔ فازی را با **معکوس‌کردن برش‌های آلفا** محاسبه و با فرمول تکه‌ای حاصل از استدلال دستی مقایسه می‌کند. فاصله‌های مورد انتظار عبارت‌اند از $d(M,D)=3/2$ و $d(N,D)=1/4$.

این محاسبات **افزودهٔ مستقل** هستند و جای اثبات‌های موجود در [مدل LR](lr-model.md)، [اصل گسترش](extension-max.md) و [روش مقایسه](kerre.md) را نمی‌گیرند.
