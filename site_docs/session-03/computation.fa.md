# جلسهٔ سوم — یادداشت‌های محاسباتی

هر دو مسئله به‌صورت **برنامه‌ریزی خطی پیوسته** حل می‌شوند. پایتون برای بررسی عددیِ مستقل به کار می‌رود و جای اثبات دستی را نمی‌گیرد. اعداد ورودی این دو مدل **از جزوهٔ جلسهٔ سوم** استخراج شده‌اند.

```bash
python -m modeling_lab transport-lecture --verify
python -m modeling_lab production-plan --verify
```

مدل حمل‌ونقل ۱۲ متغیر دارد. در جزوه، قید تقاضا $\ge$ است؛ اما در این داده‌های خاص، جمع عرضه و تقاضا برابر است و مدل با قیود تساوی نتیجهٔ یکسانی دارد. دستور قدیمی `transport-demo` مربوط به مثال عددیِ مستقل جلسهٔ دوم است و نباید با داده‌های جلسهٔ سوم اشتباه گرفته شود.

در مسئلهٔ تولید پنج‌ماهه، ۱۴ متغیر مستقل داریم: پنج تولید عادی، پنج اضافه‌کاری و چهار موجودی پایان ماه. مقادیر $s_0=s_5=0$ ثابت‌اند. حل‌کنندهٔ مشترک، هر یک از پنج قید موازنهٔ **تساوی** را با دو نامساوی پیاده می‌کند؛ این فقط شیوهٔ نمایش کامپیوتری همان مدل است.
