# Session 10 — Hesitant fuzzy sets and uncertainty in membership

**First final-exam block · source: handwritten course scan dated 10 Aban, pages 1–3.** The earlier Session 09 concludes the midterm block; this session begins the separate final-exam review.

The previous sessions used a single membership grade \(\mu_A(x)\in[0,1]\) per element. Here an evaluator can hesitate between several plausible membership grades. The mathematical object is a **hesitant fuzzy set (HFS)**.
