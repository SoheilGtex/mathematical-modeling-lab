# Assignments

The course assignments are **separate from the lecture sessions**. The original problem statements are paraphrased from submitted sources rather than copied as scans. Computational solutions and independently prepared derivations are identified clearly.

- [**Assignment 01 — Investment budgeting**](investment-budget.md): fully worked, four-year financial linear program with optimality proof and Python verification.
- [**Assignment 02 — Transportation in Python**](transportation-python.md): **only** the Python solution of the **existing Session 03 transportation exercise**; the code is already available in `examples/session_03/01_transportation.py`. There is no new problem to solve twice.
- [**Assignment 03 — Triangular fuzzy numbers and their maximum**](fuzzy-numbers-max.md): complete analytical solution of both questions, a rigorous extension-principle supremum, exact breakpoints, two graphs and optional Python verification.

The [cumulative exam review](../exam.md) covers mathematical formulations and course membership definitions, not solver output or full proofs. See each assignment page for complete solutions.
