# Assignments

These are independently worked **course assignments**, not additional lecture sessions. Each solution presents the problem data, a fully justified mathematical model, a handwritten-exam-style proof, and an optional Python verification. The assignment text is paraphrased from the student-supplied PDF; the original scanned pages are not redistributed.

- [Assignment 01 — Investment budgeting](investment-budget.md): four-year municipal financing with long-term securities and one-year deposits.

The [lecture sessions](../index.md) remain separate from these full assignments. The [cumulative exam review](../exam.md) includes the **mathematical formulation** of every assignment as well as the lecture models.
