# اعتبارسنجی جواب مدل‌های بهینه‌سازی

یادداشت‌های جلسهٔ اول مدل‌ها را **تشکیل می‌دهند** اما جواب عددی یا اثبات بهینگی ارائه نمی‌کنند. این بخش یک **توسعهٔ نرم‌افزاری مستقل** است و ادعایی دربارهٔ محتوای تدریس استاد ندارد.

## استفاده

```bash
python -m modeling_lab diet --verify
python -m modeling_lab boats --verify --json
python -m modeling_lab boats --integer --verify
python -m pytest -q
```

گزینهٔ `--verify` اختیاری است. خروجی JSON شیء `verification` را با کنترل‌ها و شواهد محاسبه‌شده اضافه می‌کند. اگر بررسی قیود اولیه مردود شود یا برای LP پیوسته گواه بهینگی قابل تأیید نباشد، برنامه با کد ۲ خاتمه می‌یابد. برای MILP ممکن است جوابِ مجاز پذیرفته شود **بدون اینکه بهینگی سراسری به‌صورت مستقل اثبات شده باشد**.

## بررسی‌های اولیه (Primal)

برای مدل خطی در قالب متداول پروژه:

\[
\operatorname{min/max} c^Tx \qquad
\text{s.t.}\ Ax\le b,\quad \ell\le x\le u,
\]

کد با استفاده از ضرایب خود `LinearProgram`، بدون اعتماد به `Solution.constraint_slacks`، موارد زیر را محاسبه می‌کند:

- نقض هر نامساوی: $\max(0,(Ax-b)_i)$.
- نقض کران‌های پایین و بالای متناهی.
- فاصلهٔ هر متغیر صحیح از نزدیک‌ترین عدد صحیح.
- تطبیق $c^Tx$ محاسبه‌شده با تابع هدف گزارش‌شده، همراه با بررسی متناهی بودن اعداد، نام متغیرها و واحد هدف.

تلرانس سطرها متناسب با مقیاس آن‌هاست: `atol + rtol * max(1, |b_i|, |a_i| @ |x|)`. پیش‌فرض‌ها `atol=1e-7`، `rtol=1e-8` و `integer_tolerance=1e-6` هستند. این‌ها **معیار پذیرش عددی** هستند، نه اثبات دقیق ریاضی برای هر دادهٔ ممیزشناور. نقض قیدها با واحد فیزیکی همان سطر گزارش می‌شود و نباید مقدار قیودِ دارای واحد متفاوت را مستقیماً مقایسه کرد.

## گواه اولیه ـ دوگان LP

یک جواب مجاز الزاماً بهینه نیست. برای LP پیوسته، کران‌های متناهی متغیرها را به سطرهای اضافی $Gx\le h$ تبدیل می‌کنیم. اگر مسئله کمینه‌سازی باشد $d=c$ و اگر بیشینه‌سازی باشد $d=-c$؛ در نتیجه مدل معادل زیر به دست می‌آید:

\[
\min d^Tx \qquad \text{s.t.}\; Gx\le h
\]

که $x$ در آن بدون محدودیت علامت جداگانه در نظر گرفته می‌شود (کران‌ها داخل $Gx\le h$ آمده‌اند). بردار دوگان مجاز $\lambda$ باید شرایط زیر را برآورده کند:

\[
\lambda\ge0,\qquad G^T\lambda=-d.
\]

کران دوگانِ ضعیف برای کمینه‌سازی برابر $-h^T\lambda$ است. بنابراین:

\[
\text{primal-dual gap}=d^Tx+h^T\lambda\ge0.
\]

اگر جواب اولیه و بردار دوگان مجاز باشند و شکاف (تا تلرانس انتخابی) صفر شود، بهینگی سراسری LP از نظر عددی تأیید می‌شود. کد یک **بردار دوگان پیشنهادی** را از SciPy/HiGHS می‌گیرد و سپس مجازبودن دوگان، معادلهٔ ایستایی و شکاف را **مستقلاً بازحساب** می‌کند؛ صرف `success` بودن حل‌کننده کافی نیست. با این حال حل‌کننده و بررسی‌کننده به حساب ممیزشناور و بخشی از وابستگی‌های مشترک متکی‌اند؛ این اثبات صوری یا حساب دقیق نیست.

این گواه دوگان خطی نیازی به فرض مشتق‌پذیری شرایط KKT ندارد.

## محدودیت‌های MILP و کران حل‌کننده

برای جواب‌های MILP، قیود، سازگاری مقدار تابع هدف و صحیح‌بودن متغیرها مستقل بررسی می‌شوند. حل‌کننده ممکن است کران دوگان و شکاف نسبی گزارش کند. کد، کران `scipy.optimize.milp` را از جهت کمینه‌سازی داخلی به جهت تابع هدف اصلی تبدیل می‌کند:

- **بیشینه‌سازی:** کران حل‌کننده باید کران **بالا** برای سود بهینه باشد.
- **کمینه‌سازی:** کران حل‌کننده باید کران **پایین** برای هزینهٔ بهینه باشد.

کران سازگار با عنوان `milp_solver_bound` مشخص می‌شود و **گواه مستقل بهینگی سراسری نیست**. برای اثبات اعتبار آن باید شواهد اضافی Branch-and-Bound / Cutting-Plane یا روش دقیق مستقلی بررسی شود. در نتیجه مقدار `independent_optimality_verified` برای MILP برابر `false` می‌ماند. همین تمایز برای توسعهٔ رژیم غذایی که فقط تعداد تخم‌مرغ در آن صحیح است نیز برقرار است.
